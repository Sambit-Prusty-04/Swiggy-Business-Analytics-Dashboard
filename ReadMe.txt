# Swiggy Business Analytics Dashboard

This project contains an Excel-based dashboard analyzing Swiggy’s performance metrics.  
It provides insights into **sales, ratings, orders, and customer behavior** across time, geography, and food categories.

## 📊 Key Features
- Total Sales, Average Rating, Order Value, and Rating Count KPIs
- Monthly, Weekly, and Daily Sales Trends
- Sales by Food Type (Veg vs Non-Veg)
- Sales by State (India map visualization)
- Quarterly performance summary
- Top 5 cities by sales
- Interactive filters for restaurant, category, and months
